# آيات - ودجت قرآني (Android)

## طريقة الحصول على APK بدون Android Studio
1. أنشئ مستودعاً (Repository) جديداً على GitHub وارفع محتويات هذا المجلد كلها.
2. افتح تبويب Actions ← "Build APK" ← Run workflow (يعمل تلقائياً مع كل رفع).
3. بعد دقائق نزّل ملف `QuranWidget-APK` من أسفل صفحة التشغيل، وفيه `app-debug.apk`.
4. ثبّته على الهاتف (اسمح بالتثبيت من مصدر غير معروف).

## أو بـ Android Studio
افتح المجلد ← Build ← Build APK(s).
